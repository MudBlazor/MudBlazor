# Guide d'installation et d'utilisation de la librairie MudBlazor

## Comment installer le projet

1. Cloner le repo suivant dans Rider : https://github.com/xdaneault/MudBlazor.git
2. Ouvrir le terminal dans Rider et faire la commande `git checkout test/local-playground`
3. Cette branche contient tous les changements que j'ai apportés localement au projet MudBlazor
4. Le dernier projet de la solution devrait être s'appeler `MudBlazorTest`
5. Faite clic droit sur ce projet et appuyé sur `Run MudBlazorTest: http ...`
6. Cela devrait lancer le petit projet de test que j'ai créé pour tester les changements que j'ai apportés à la librairie.
7. Sur la page `Home` de ce même projet, il devrait y avoir tous les éléments nécessaires pour tester tous les changements que j'ai apportés à la librairie.

Le projet de test a comme référence la librairie officielle MudBlazor donc tous les changements effectués dans la librairie sont traduits dans le projet de test.
